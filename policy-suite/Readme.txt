Instructions:
1) There are six policies, indexed by 'x' \in {1,2,...,6}.
2) Go to .../pol'x' folder.
3) Open << RUN_ME_pol'x'.m >> in the script editor.
4) Set SPEC \in {'baseline','equal_shares','auto33','acemoglu2020'}.
5) Run << RUN_ME_pol'x'.m >> from the command window. 

Notes: 
1) Install the Global Optimization and Parallel Computing toolboxes.
2) The *.mat files from the calibration suite for each SPEC should be in 
the pol'x' folder.
3) Run the 'baseline' SPEC under Policy 1 to generate Figure 4.
4) Run the 'baseline' SPEC under Policy 6 to generate Figure 5.
5) Please send your comments or corrections to << maattar@gmail.com >>.
